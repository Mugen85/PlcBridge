========================================================= GUIDA ALL'AVVIO - PLC BRIDGE (Architettura ad Host)
Con il recente refactoring verso la Clean Architecture e il .NET Generic Host, 
l'applicazione non è più divisa in comandi testuali "server" e "client".

Il sistema è ora un unico eseguibile (PlcBridge.Worker) che gestisce autonomamente:

•	Il motore di I/O (Simulatore o PLC reale) in un thread in background.
•	L'interfaccia di monitoraggio sul thread principale.

=== PREREQUISITI ===

•	.NET SDK 10 installato sul sistema.

•	Terminale posizionato nella cartella radice del progetto (dove risiede il file .sln).

=== PROCEDURA DI COMPILAZIONE ===

1.	Ripristinare i pacchetti NuGet (Serilog, Spectre.Console, Microsoft.Extensions.Hosting):

dotnet restore

2.	Compilare l'intera solution per assicurarsi che i link tra Core, Infrastructure e Worker siano corretti:

dotnet build

=== PROCEDURA DI ESECUZIONE ===

1.	Spostarsi all'interno della cartella del Worker:

cd PlcBridge.Worker

2.	Avviare l'applicazione:

dotnet run

L'applicazione si avvierà mostrando i log di Serilog in console.
In background, il "PlcPollingWorker" comincerà automaticamente a
 connettersi al Driver PLC (attualmente il simulatore in locale) e a leggere i dati in modo ciclico.
 
Per arrestare il sistema in modo pulito (Graceful Shutdown), premere il tasto: ESC.
I file di log dettagliati vengono salvati automaticamente nella cartella: PlcBridge.Worker/logs/
